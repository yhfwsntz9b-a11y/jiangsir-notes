多 Agent ≠ 多工具

每个 Worker 是独立推理单元：自己的 Prompt、工具、权限和上下文。

只是多挂几个工具，仍然是一个 Agent。

拓扑不止一种

Supervisor：中心调度，适合任务拆解与汇总。

Handoff：Worker 之间互相转交；Pipeline：按顺序流水线。

本图是 Supervisor；拓扑变了，连线和状态协议也要变。

共享状态要定协议

谁写、写什么、什么版本、何时算完成，都要约定。

否则 Worker 会互相等待、重复劳动或循环转派。

成本与收敛

设 max_turns、预算、超时；Supervisor 必须负责最终收敛。

多 Agent 的代价是 token 和延迟成倍增长。

多 Agent 的核心不是“开很多个模型”，而是分工、状态协议与收敛机制；否则只是更贵的循环。
