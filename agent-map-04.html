Reflection 不是内置算法

它只是多一次 LLM 调用 + 一条回边：Actor 出稿，Critic 评审，未通过就回去改。

AgentExecutor 本身不会“反思”；图里加了 Critic 节点才有。

Critic 必须独立

用同一个上下文“再想一遍”，往往只会自我确认。

独立 Prompt / 独立上下文 / 必要时独立模型，只让它看产物和标准。

一定要能退出

没有通过条件，反思会变成无限改稿。

设置 max_rounds、token 预算和降级出口；不通过也比卡死好。

嵌套框 = 包含

绿色回环 = 循环反馈
琥珀虚线 = 本图新增 / 变化
反思的收益来自“独立标准 + 独立视角”；没有 rubric 和退出条件的自省，只是更贵的自我确认。
