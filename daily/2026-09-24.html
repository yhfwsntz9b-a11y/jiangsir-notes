📚 学习价值

  • 主要语言: C
  • Stars: ⭐ 44,567 | 今日 新上榜 🆕
  • 项目地址: GitHub

📖 项目介绍

用 C 语言实现的高性能代码智能 MCP 服务器，把整个代码库索引成持久化知识图谱。

项目官方描述：High-performance code intelligence MCP server. Indexes codebases into a persistent knowledge graph — average repo in milliseconds. 158 languages, sub-ms queries, 99% fewer tokens. Single static binary, zero dependencies.

✨ 技术亮点

  • 知识图谱而非向量检索: 保留精确的函数调用关系、模块依赖、类型定义，回答「这个函数被谁调用」零幻觉
  • 极致性能: 毫秒级索引普通仓库、亚毫秒级查询，158 种语言支持
  • Token 节省 99%: Agent 无需反复扫描源码，上下文消耗大幅降低
  • 单二进制零依赖: C 实现带来极低内存占用，部署即拷即用

🎯 适合场景

大型代码库的 AI 辅助开发、给 Claude Code/Cursor 等工具加装持久代码记忆、代码影响面分析

📚 学习价值

理解 MCP 协议的工程化应用，对比知识图谱与向量 RAG 在代码理解任务上的本质差异。
