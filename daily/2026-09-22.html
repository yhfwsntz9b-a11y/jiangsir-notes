7. tamaratran/fast-jev-compaction — 用 Jev 决策替代上下文压缩

🏷️ 基本信息

  • 分类: 上下文工程 / Claude Code 插件
  • 主要语言: TypeScript
  • Stars: ⭐ 5,980 | 今日 +781
  • 项目地址: GitHub

📖 项目介绍

连续两日霸榜（昨日 5,199，今日 5,980）。Claude Code 插件，用"Jev 决策"替代默认的上下文压缩摘要——长对话不再做有损的 LLM 摘要，而是提取关键决策点。

项目官方描述：Claude Code plugin that replaces the compaction summary with Jev decisions.

✨ 技术亮点

  • 决策点提取：压缩时保留"做过什么选择、为什么、改变了什么状态"，而非叙述文本
  • 零成本压缩：压缩本身由轻量决策模型完成，几乎不消耗大模型 token
  • 无损恢复：长会话的上下文恢复精度显著高于摘要式压缩
  • 插件切入：不改造框架本体，用替换内部机制的方式低成本切入

🎯 适合场景

Claude Code 深度用户、长会话编程工作流、上下文工程实践者。

📚 学习价值

上下文工程（context engineering）的最小可行产品范本——示范了"插件替换一个内部机制"这种四两拨千斤的产品策略。

  • 闭环修正：执行结果实时回传规划端，方向随时校准

🎯 适合场景

已有 ChatGPT + Codex 订阅的开发者、复杂任务的长链路规划、多 Agent 协作实验。

📚 学习价值

异构模型协作的接口设计是核心工程问题——这个项目展示了"信息格式契约"在多模型系统中的关键作用。
