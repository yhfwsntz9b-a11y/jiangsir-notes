和 ReAct 的区别

ReAct 是边想边做，每一步都重新决定。

Plan-and-Execute 先想全局，再让 Executor 逐步做；计划本身是状态。

经典实现不会自动重规划

原始 PlanAndExecute 只按计划执行，失败就失败。

Replanner 是额外加的编排节点，用于失败或出现新信息时改计划。

计划要能验收

每一步都要有完成标准，否则 Executor 不知道何时算做完。

max_steps 和预算必须设；否则计划过长会烧穿成本。
